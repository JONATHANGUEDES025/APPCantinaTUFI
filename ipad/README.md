# Cantina TUFI iPad

Versao PWA offline do Cantina TUFI.

## Como usar no iPad

1. Abra o link da versao iPad no Safari.
2. Toque em Compartilhar.
3. Toque em Adicionar a Tela de Inicio.
4. Abra pelo icone Cantina TUFI.

Depois de instalada, a versao iPad salva os dados no proprio aparelho.

## Importante

- Nao precisa de Python.
- Nao precisa de PC ligado depois de instalada.
- Os dados ficam somente no iPad usado.
- Para seguranca, use Exportar backup com frequencia.
- Para trocar de iPad, exporte o backup no iPad antigo e importe no novo.
